# Laba1

Минимальное WPF-приложение на C# для практики событий интерфейса.

Сейчас проект содержит главное окно и обработчик нажатия кнопки. Это учебный пример, а не готовое пользовательское приложение.

## Запуск

Откройте `Laba1.sln` в Visual Studio с поддержкой WPF. Сборка и запуск зависят от установленной версии .NET Framework, указанной в проекте.
